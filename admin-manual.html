🌍 Section 05

Custom Domain — lms.lithala.com

Point lms.lithala.com to the GitHub Pages site so learners can access it on the Lithala domain. This requires a DNS record change and one GitHub setting.

What you need

  • Login to your domain registrar (Domains.co.za, Afrihost, Hetzner, Xneelo, etc.)
  • Ability to add DNS records
  • GitHub repository Settings access
  • Allow 24–48 hours for DNS to propagate

Two options

  • Subdomain Recommended
    lms.lithala.com → easiest
  • Root domain Advanced
    lithala.com → replaces main site

Option A — Subdomain: lms.lithala.com Recommended

1

Log in to your domain registrar

Log in and find DNS Management or DNS Records for lithala.com.

2

Add a CNAME record exactly as shown below

TypeHost / NameValue / Points toTTL
CNAMElmslithala-lms.github.io3600

Host = just lms — the registrar adds .lithala.com automatically.
Value = lithala-lms.github.io — no trailing slash, no /LMS at the end.

3

Set the custom domain on GitHub Pages

Go to repository → Settings → Pages → Custom domain → type lms.lithala.com → Save. GitHub creates a CNAME file in your repo automatically.

4

Tick "Enforce HTTPS" on GitHub Pages

After DNS propagates (up to 48h), the Enforce HTTPS checkbox becomes available. Tick it for the padlock icon and secure connection.

5

Update SITE_URL in lms-config.js

SITE_URL: 'https://lms.lithala.com'

Also add https://lms.lithala.com to Google OAuth authorised origins — see Section 09.

Save

Option B — Root domain: lithala.com Advanced — replaces main site

⚠️

This replaces your existing lithala.com website

Only do this if you want the LMS to be your primary website. If you have an existing WordPress or other site, it will stop working.

Add these 4 A records in your DNS (instead of the CNAME above):

A@ or blank185.199.110.1533600
A@ or blank185.199.111.1533600

Then set Custom domain on GitHub to lithala.com and update SITE_URL in lms-config.js.

⚙️ Section 07

Google Apps Script — The Backend

Apps Script receives data from the website, writes to Google Sheets and sends emails. It is deployed as a Web App and given a URL. Every time you change the code, you must create a new deployment and update the URL in lms-config.js.

🚨

Critical: New deployment required after every code change

Saving the Apps Script does NOT update the live endpoint. You must Deploy → New Deployment after changes, then copy the new URL into lms-config.js on GitHub.

1

Open the Google Sheet

Go to sheets.google.com and open the Lithala LMS sheet, signed in as lithalalms@gmail.com.

2

Click Extensions → Apps Script

Opens the Apps Script editor in a new tab.

3

Paste the updated code from google-apps-script.js

Delete all existing code, paste the new code, click Save (💾).

4

Click "Deploy" → "New deployment"

5

Configure the deployment

  • Type: Web app
  • Execute as: Me (lithalalms@gmail.com)
  • Who has access: Anyone
6

Copy the Web App URL and update lms-config.js

The URL looks like https://script.google.com/macros/s/XXXX/exec. Copy it and update SCRIPT_URL in lms-config.js on GitHub.

💳 Section 10

PayFast Integration

PayFast is the South African payment gateway. Currently in sandbox (test) mode. To accept real payments, create a PayFast merchant account and add your credentials.

1

Register at payfast.co.za → merchant account

You need your SA ID number, bank details and CIPC company registration number. Approval can take 2–5 business days.

2

Get Merchant ID and Merchant Key

In your PayFast dashboard: Settings → Integration. Both credentials are shown there.

3

Update lms-config.js on GitHub

lms-config.js — PayFast section
PAYFAST: {
  MERCHANT_ID: '10012345', // Replace with your real Merchant ID
  MERCHANT_KEY: 'abcdef0123456789', // Replace with your real Merchant Key
  PASSPHRASE: 'YourPassphrase', // Set in PayFast dashboard → Integration
  SANDBOX: false, // Change true → false to go live
},

lms-config.js — Full Reference

The single most important file. All configuration lives here. Edit on GitHub, commit, live within 2 minutes.

lms-config.js — annotated reference
const LMS = {

  // ─── BACKEND ─────────────────────────────────────────────
  SCRIPT_URL: 'https://script.google.com/macros/s/XXX/exec',
  // Update every time you redeploy the Apps Script ↑

  SHEET_ID: '110-K93UME8_8z5pystKKc5yIsoAC1_OdKyt4KSs0oco',
  // Just the ID — no /edit?usp=sharing ↑

  SITE_URL: 'https://lms.lithala.com',
  // Update when custom domain is live ↑

  GOOGLE_CLIENT_ID: '811534121376-d1v193...apps.googleusercontent.com',

  ADMIN_PASSWORD: 'LithalaAdmin2025', // ← Change this
  ADMIN_EMAILS: ['info@lithala.com', 'lithalalms@gmail.com'],

  PAYFAST: {
    MERCHANT_ID: 'YOUR_ID', // from payfast.co.za
    MERCHANT_KEY: 'YOUR_KEY',
    SANDBOX: false, // true = test, false = live
  },

  COURSES: [ /* 8 course objects + any you add via course-editor.html */ ]
};
⚠️

When to update lms-config.js

  • After redeploying Apps Script → update SCRIPT_URL
  • After setting up custom domain → update SITE_URL
  • When adding PayFast → update PAYFAST block
  • To change admin password → update ADMIN_PASSWORD
  • To change result email addresses → update ADMIN_EMAILS

🔧 Section 14

Troubleshooting Reference

Common issues with root cause and fix.

!

Site shows old content after uploading

Fix: Hard refresh — Ctrl+Shift+R (Windows) or ⌘+Shift+R (Mac). On mobile, clear browser cache.

!

Google Login: "Error 400 — redirect_uri_mismatch"

Cause: New domain not added to OAuth authorised origins. Fix: Section 09 — add domain in Google Cloud Console.

!

Data not saving to Google Sheet

Cause: SCRIPT_URL in lms-config.js is outdated. Fix: Redeploy Apps Script, copy new URL, update lms-config.js.

!

No result emails received

Cause 1: Wrong SCRIPT_URL. Cause 2: Apps Script daily email quota hit (100/day on free Gmail). Fix: Upgrade to Google Workspace (R180/user/month) for higher quota.

!

Custom domain shows GitHub 404

Cause 1: DNS not propagated yet — wait 48h. Cause 2: CNAME points to wrong value — must be lithala-lms.github.io NOT lithala-lms.github.io/LMS. Cause 3: CNAME file deleted from repo — re-set custom domain in GitHub Pages settings.

!

PayFast payments not confirmed in Sheet

Cause: ITN Notify URL in PayFast dashboard is wrong. Fix: Log in to PayFast → Settings → Integration → update Notify URL with current Apps Script URL.

!

Admin panel password not working

Fix: Check ADMIN_PASSWORD in lms-config.js on GitHub. The password is case-sensitive.
